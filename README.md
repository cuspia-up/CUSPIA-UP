# CUSPIA UP

Sitio institucional del **Centro Universitario de Sistemas y Proyectos de Inteligencia Artificial**, Facultad de Ingeniería, Universidad de Palermo.

## Publicación con GitHub Pages

El sitio es estático y no requiere instalación ni compilación.

1. Abrir `Settings → Pages` en el repositorio.
2. En `Build and deployment`, elegir `Deploy from a branch`.
3. Seleccionar la rama `main` y la carpeta `/ (root)`.
4. Guardar.

GitHub publicará el sitio desde los archivos de la raíz del repositorio.

## Edición

- `index.html`: contenido y estructura.
- `styles.css`: identidad visual y diseño adaptable.
- `script.js`: menú móvil y animaciones sutiles.

Antes del lanzamiento institucional se deben confirmar el correo de contacto, la dirección exacta, la denominación de cargos y el uso de las marcas de la Universidad de Palermo.
